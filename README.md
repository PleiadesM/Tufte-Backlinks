# Tufte Backlinks

An [Obsidian](https://obsidian.md) plugin that renders Linked/Unlinked mention snippets as formatted Markdown in the Backlinks pane and the in-document backlinks block: headings sit at body size, the backlink reference itself is bold, underlined, and accent red, and match highlights are preserved. The global Search pane is left untouched.

Part of [**Tufte for Obsidian**](https://github.com/PleiadesM/TufteObsidian) — a theme and plugin suite carrying Edward Tufte's book design into Obsidian. **Development, documentation, and issues live in the main repository**; this repository exists to distribute the plugin through the Obsidian community directory.

## Install

- **Manual:** download `main.js`, `manifest.json`, and `styles.css` from the [latest release](../../releases/latest) into `YourVault/.obsidian/plugins/tufte-backlinks/`, then enable the plugin in Settings → Community plugins.
- Pairs best with the [Tufte theme](https://github.com/PleiadesM/TufteObsidian).
